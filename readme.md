### What is it?

- Think in maps: add, move and reorganise topics without leaving the keyboard
- Notes, tasks, files and links on every topic
- Outline view, focus mode and presentations
- Themes, shapes, boundaries, summaries and cross-links
- Import and export (Markdown, OPML, images, PDF and more)
- Syncs across every device you sign in on
- A native macOS app that updates itself

### Download

Use it in the browser at [notemap.com](https://notemap.com), or get the macOS app from the [latest release](https://github.com/notemap/notemap/releases/latest) (one universal `.dmg` for Apple Silicon and Intel). The app keeps itself up to date.

### Changelog

Every release and what changed is on the [releases page](https://github.com/notemap/notemap/releases). The app shows the same notes under **What's new** in the account menu.
